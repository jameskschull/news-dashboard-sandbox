# News Dashboard

A modern, real-time news dashboard application for aggregating and displaying news from multiple sources.

## Features

- Real-time news updates
- Multiple news source integration
- Customizable dashboard layout
- Search and filter capabilities
- Responsive design

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
